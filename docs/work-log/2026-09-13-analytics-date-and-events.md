# 관리자 분석: 날짜 조회, 비교, 콘텐츠 행동

- 오늘·어제·7/30/90일·직접 선택. 직접 선택은 시작일과 종료일을 포함하며 최대 90일.
- 한국 시간 자정을 UTC 타임스탬프로 변환. API의 종료 시각은 포함 조건이므로 다음 날 자정에서 1ms를 뺀다. 오늘은 호출 시각까지.
- 날짜별 방문자는 한국 시간의 하루씩 `environment` 그룹으로 조회한다. UTC 일별 방문자 또는 시간별 방문자를 더해 한국 시간 순 방문자처럼 표시하지 않는다.
- 여러 날의 방문자 합계는 날짜 사이 중복이 있으므로 ‘일별 방문자 합계’로 표시한다.
- 일별 조회·클릭 합계, 하루의 시간별 조회, 날짜 상세 링크, 이전/다음 날, 인증된 새로고침 추가. 캐시 60초. 날짜별 API 호출은 4일씩 처리한다.
- 비교는 선택 기간 바로 앞의 같은 일수. 오늘 포함 기간은 집계 중이며 이전 기간은 하루 전체임을 명시한다. 이전 값 0에서는 증가율을 계산하지 않는다.
- 보관 기간 밖의 데이터는 복구하지 않는다. API 오류는 0건 정상 응답과 구분한다.

## 이벤트 계약

| 이벤트                    | 속성                       | 집계 의미                                             |
| ------------------------- | -------------------------- | ----------------------------------------------------- |
| Post Click                | postId, placement          | 기존 게시물 클릭 유지                                 |
| Recommendation Impression | postId, placement          | 링크 50% 이상 화면 노출 또는 실제 클릭                |
| Recommendation Click      | postId, placement          | 동일 페이지·게시물·위치별 첫 클릭                     |
| Content Action            | action, question 또는 path | 학습 탭 열람 / 다운로드 링크 클릭 / SNargen 링크 이동 |

- 추천 노출·클릭은 기존 클릭과 별도 집계. 페이지 이동 때 중복 방지 상태를 초기화한다. 페이지뷰와 날짜 경계에 걸친 이벤트 집계, 차단된 요청 등에 따른 차이가 있을 수 있으므로 클릭률을 임의로 100%에 고정하지 않는다.
- 학습 탭은 통합사회·통합과학 25문항의 문제와 풀이, 변형문제 탭, 역분해, 유사 기출을 구분한다. 현재 변형문제 탭 열람은 문제 제작 완료를 뜻하지 않는다.
- 다운로드는 `download` 속성 링크 및 동일 출처 PDF/ZIP/HWP/HWPX 링크 클릭. 저장 완료를 뜻하지 않는다.
- SNargen 이동은 snargen.com 및 하위 도메인 링크에 적용. 링크가 없다면 해당 이벤트도 발생하지 않는다.
- 이름, 이메일, 검색어, 쿼리 문자열, 클릭 문구를 이벤트 속성에 보내지 않는다. 새 지표는 배포 이후 수집분만 존재한다.

## 검증

- `npm run test:analytics`: 한국 시간 경계, 윤년/연말, 잘못된 날짜, 최대 기간, API 요청 구간, 이전 기간, 오류 상태, 추천 중복 방지, 관리자 HTML 렌더링.
- `npm run type-check`, 변경 파일 ESLint.
- 로컬 분석 토큰이 없어 실제 Vercel 통계 호출은 미검증. 테스트는 모의 응답을 쓰고 실제 분석 이벤트를 전송하지 않는다.

API 기준: [Vercel Web Analytics API](https://vercel.com/docs/analytics/web-analytics-api), [집계 조회 파라미터](https://vercel.com/docs/rest-api/web-analytics/aggregates-page-views).
