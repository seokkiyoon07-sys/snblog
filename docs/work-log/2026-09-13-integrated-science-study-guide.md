# 통합과학 학습 가이드 초안 게시글

- MD 초안을 `content/integrated-science-problem/2028-integrated-science-study-guide.html`로 구성했다. 통합사회 가이드의 색상·폭·요약 카드·목차·표·학습 단계 스타일을 적용하고 모바일 카드형 표와 다크 모드 스타일을 유지했다.
- `post-records.ts`에 통합과학 카테고리의 게시글을 등록했다. 주소는 `/problem-download/2028-integrated-science-study-guide`이며 초안 표시와 통합과학 썸네일을 연결했다.
- 8개 본문 섹션, 2개 표, 5단계 학습법, 분석 페이지 이동 링크를 구성했다. 표의 25개 문항 번호와 본문 번호 링크에서 과학 원문을 열도록 BlogLayout의 기존 사회 팝업 처리를 확장했다. 과목별 데이터와 이미지·제목을 분리했다.
- TypeScript 통과, ESLint 오류 없음. BlogLayout의 기존 any 및 복잡한 의존성 표현 경고 10건은 남아 있다.
- 과학 가이드·사회 가이드·문제 목록 HTTP 200을 확인했다. 목차 8개 앵커, 과학 문항 25개 연결, 표의 모바일 레이블 36개와 학습 단계 마크업을 검사했다.
- 연결된 브라우저가 없고 agent-browser CLI를 사용할 수 없어 실제 화면 캡처·팝업 클릭 검증은 수행하지 못했다. 시각·클릭 검증을 완료했다고 보고하지 않는다.
- 로컬 게시글 등록만 했으며 커밋·배포하지 않았다.
- 과목별 분석 추가: 핵심 판단 대상에 따라 각 문항을 한 번씩 배정해 물리 6·화학 6·생명 6·지구 7문항으로 집계했다. SVG 4축 레이더(축 0~10), 25문항 전체 분류표, 복합 문항의 배정 이유 및 목차 링크를 추가하고 MD 초안에도 반영했다. 공식 비율·난도 분포가 아닌 SN의 주된 과목 분류임을 명시했다.
- 레이더의 실제 좌표와 총 25문항 중복·누락 여부를 검사했다. SVG를 PNG로 렌더링해 한글·숫자·축·라벨 배치를 확인했고 페이지 HTTP 200 및 차트 마크업 반영을 확인했다.
- 사용자 정정 반영: 위의 단일 주과목 분류를 폐기하고 실제 연결 개념을 모두 기록하는 중복 집계로 교체했다. `integrated-science-subjects.ts`에 25문항의 과목·개념·풀이 역할을 저장했으며 물리 12·화학 11·생명 10·지구 10문항, 총 43건(복수 과목 문항 13개)이다. 단순 소재·일반적 자료 해석·한계 반응물 비유 등은 추가 과목으로 세지 않는다.
- 레이더 축과 카드 클릭으로 `ScienceSubjectModal`을 열고 과목별 문항·개념·풀이 역할·함께 연결된 과목을 비교하도록 구현했다. 과목 전환, 원문·해설 새 탭 링크, 닫기·Escape 및 모바일 카드형 표를 지원한다. 본문에도 25문항 개념 대응표를 제공한다.
- `npx tsx scripts/build-science-subject-section.ts`로 같은 분석 데이터에서 정적 차트·버튼·전체 표·MD를 생성한다. 과목 내 문항 중복과 25문항 누락을 검사한다. 비율의 분모는 각각 25이며 합계가 100%를 넘는 이유를 설명했다.
- 최신 검증: TypeScript 통과, 신규 데이터·모달 ESLint 오류/경고 없음. BlogLayout 기존 경고는 유지. HTTP 200, 과목 링크 4개·버튼 4개·모달 마크업 및 전체 표 25행 확인. 연결된 브라우저와 로컬 브라우저 테스트 도구가 없어 실제 클릭 검증은 수행하지 못했다.
- 학습 가이드 전용 썸네일: 통합사회 PNG를 시각적으로 확인하고 짙은 녹색 배경·테두리·중앙 3행 제목·상단 배지·하단 설명을 맞춘 1920×1080 SVG를 제작했다. `2028-integrated-science-study-guide.svg`를 해당 게시글에 연결했으며 예시문항 분석 글의 기존 썸네일은 유지했다. SVG 렌더링으로 한글·배치를 확인하고 파일·게시글·목록 HTTP 200 및 새 경로 반영을 확인했다.
- 글 구조 보완: 여섯 학습 범주를 유지하고 개념·사례, 측정·물리량, 지구시스템 절을 신설했다. 표의 범주에 해당 본문 앵커·절 번호를 연결하고 25문항 모두 본문에서도 설명했다. 과목 연계 차트를 2절로 편입해 12개 목차와 1~12절 번호를 일치시켰다. 4·11·22번 및 SNarGEN 제작 계획에서 과목 연계 분석을 인용했다.
- 6번 습도 변화량의 축소 표현과 25번 깊이 축의 불필요한 유보 표현을 고쳤다. 1절은 판단 유형을 안내하도록 전환하고 양적 관계 절에 단위·상한·잉여량·운동 조건 소제목을 추가했다. 공개 eyebrow·badge의 초안 표기를 제거하고 읽기 시간을 갱신했다.
- SNarGEN 계획 추가: 자료 표현·실험 조건·중간 계산·과목 융합·반례 판단의 다섯 제작 방향, 오답 설계, 교육과정·정답·자료 검토, 단계별 문제와 25문항 종합 세트 제공 계획을 반영했다. 실제 변형문제는 작성하지 않았다. 12·15·16번 유사 기출의 실제 선택지 배열은 변경하지 않았다.
- `npx tsx scripts/build-science-study-guide.mjs`로 MD 본문을 공개 HTML에 반영하고 과목 차트도 함께 갱신하도록 생성 경로를 마련했다. 현재 통계 12·11·10·10(43건)은 유지한다.
- 검증: TypeScript 통과. 목차 12개와 제목 12개 순서 일치, 표·과목 차트를 제외한 본문에서 25문항 연결 확인, 공개 HTML 초안 표기 제거, 과목 트리거 8개 유지, 게시글 HTTP 200 및 목록 연결 확인.
- 후속 문장 검토 반영: 11절 끝에 자료·판단 근거·다른 문제에 적용할 방법의 세 질문을 복원하고 도입 질문으로 돌아오는 마무리를 추가했다. 12절 도입에 후속 제작 계획임을 밝히고 세 학습 단계와 다섯 제작 방향을 연결했다. 이 가이드의 본문·목차 브랜드를 기존 통합과학 게시글과 같은 SNargen으로 통일했다. 공개 문구의 모달은 상세 창 또는 과목별 연계 분석으로 바꿨다.
- MD와 생성 스크립트를 함께 수정한 뒤 HTML을 재생성했다. 11절의 세 질문, 12개 절 유지, 공개 HTML의 브랜드·용어 정리 및 HTTP 200으로 변경된 본문 제공을 확인했다.
