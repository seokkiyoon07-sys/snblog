# 2026-09-10 SN Originals 소개 글 가독성 수정

## 원인

`/originals/sn-originals-intro`의 본문 파일에서 Markdown 제목·본문·목록이 같은 문단으로 합쳐져 있었다. 줄바꿈이 소제목 중간을 끊고, 지원하지 않는 `<callout>` 태그도 섞여 있어 화면에서 제목 일부와 본문이 붙어 표시됐다.

## 수정

- `content/originals/sn-originals-intro.html`을 명확한 HTML 구조로 정리했다.
- 8개 소제목, 짧은 문단, 3개 목록과 인용문으로 내용을 나눴다.
- 원래의 소개 취지, 학습 철학, 두 본문 이미지, 유튜브 채널 링크를 유지했다.
- 긴 문장과 어색한 표현을 다듬고 글자 크기·줄간격·단락 간격을 지정했다.
- 지원하지 않는 callout을 일반 HTML 안내 상자로 바꿨다.
- 2025년 당시 업로드 및 서비스 계획은 과거 계획임을 명시했다.
- 이 글의 화면 제목만 짧게 정리하고 크기를 줄였다. 메타데이터 제목과 다른 글의 화면 제목은 유지한다.
- 공통 Markdown 렌더러는 수정하지 않았다.

## 검증

- 변경 TSX lint 및 TypeScript 검사 통과.
- 개발 서버에서 제목·문단·목록의 DOM 구조 확인.
- 데스크톱·모바일 화면과 본문 링크 확인, 브라우저 오류 없음.
- 개발 서버는 사용자가 계속 확인할 수 있도록 유지한다.

운영 반영은 기존 main 푸시 → Vercel 자동 배포 경로를 사용한다.
