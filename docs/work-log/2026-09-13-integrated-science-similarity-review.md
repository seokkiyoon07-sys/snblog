# 통합과학 1~7번 유사문제 14개 재검토

## 범위와 기준

등록된 예시문항 원문 1~7번과 유사문제 PNG 14개의 자료·선지를 비교했다. 유사도는 문항 전체가 동일하다는 뜻이 아니라, 원문의 핵심 개념과 판단 과정이 실제 선지에서 겹치는 정도를 뜻한다.

- 직접 유사: 원문 핵심 선지와 같은 개념·분류·대응을 실제로 묻는다.
- 개념 연계: 일부 개념 또는 자료 읽기 방법은 겹치지만 중심 과제가 다르다.
- 확장 학습: 같은 단원이나 그래프 형태를 공유하나 원문 풀이에 직접 대응하는 부분은 약하다.

학년도·시험명과 공식 정답의 외부 대조는 이번 유사도 검토 범위에 포함하지 않았다. 기존 화면의 시험 정보는 제공 원고 기준이며 PNG에는 시험 머리말이 없다. 코드와 게시물은 수정하지 않았다.

## 결론

14개 중 직접 유사 8개, 개념 연계 4개, 확장 학습 2개로 판단한다. 이는 점수화한 검색 지표가 아니라 원문과 선지의 대응을 근거로 한 검토 의견이다.

1번은 직접 유사한 문제를 확보했다고 보기 어렵다. 외래종의 생태계 영향과 관리, 환경 오염과 온난화의 사례 구분을 실제로 묻는 자료를 추가로 찾는 편이 좋다. 6번은 월별 상대 습도의 구간 변화량 비교, 여러 세로축 구분, 관측자료 전처리 중 하나를 직접 묻는 자료가 더 적합하다.

현재 자료는 학습상 쓸모가 있지만 모두를 동일한 강도의 유사 기출로 소개하면 과장된다. 직접 유사·개념 연계·심화 자료를 구분해 표기하는 것이 적절하다. ‘동일 소재’만으로 ‘동일 문항’, ‘출제 원천’, ‘기출 재조립’이라고 단정할 근거는 없다.
