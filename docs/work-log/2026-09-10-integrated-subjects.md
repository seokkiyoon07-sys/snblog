# 2026-09-10 문제 다운로드 통합사회·통합과학 추가

## 변경 내용

- `/problems`의 국어·수학·영어 옆에 통합사회·통합과학 독립 과목 탭을 추가했다.
- 기존 사회탐구·과학탐구 설정과 별도로 분류했다.
- 전체 목록과 과목별 자료 수 계산에 새 카테고리가 포함된다.
- 아직 등록된 자료가 없어 두 과목은 각각 0건과 기존 준비 중 안내를 표시한다.
- 페이지 설명과 검색 키워드에 새 과목을 반영했다.
- 모바일에서도 새 과목을 바로 볼 수 있도록 상위 과목 탭을 줄바꿈한다.

| 과목     | 글 메타데이터 category       |
| -------- | ---------------------------- |
| 통합사회 | `integrated-social-problem`  |
| 통합과학 | `integrated-science-problem` |

이 카테고리로 공개 글을 등록하면 해당 탭과 전체 목록에 표시된다. 실제 문제 자료는 이번 작업에서 추가하지 않았다.

## 변경 파일

- `src/lib/config.ts`: 새 과목 설정
- `src/components/ProblemsTabs.tsx`: 탭 노출과 과목별 색상
- `src/app/problems/page.tsx`: 메타데이터

## 검증 및 배포 방식

- 변경 파일 lint: 경고·오류 없음.
- Node 22 프로덕션 빌드 및 타입 검사: 통과, 정적 페이지 147개 생성.
- 프로덕션 로컬 서버에서 두 과목 탭을 클릭하고 각각의 빈 목록 안내 확인.
- 모바일 화면 캡처 확인, 브라우저 오류 없음.
- 기존 main 푸시 → Vercel Git 연동 배포 방식을 사용한다.
