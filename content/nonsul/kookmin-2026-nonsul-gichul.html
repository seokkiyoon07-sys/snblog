[1]국어 · 문학 — 김훈 「회상」·김소연 「최초의 경험」11.5점

(가)는 "꽃은 피었다"를 "꽃이 피었다"로 고친 경험을 들어 사실의 언어와 정서의 언어를 구별해야 한다고 말하는 글입니다. (나)는 강요의 말이던 "해야 돼."가 '건성'과 결합하자 해방감을 준 최초의 경험을 담은 글입니다.

(1) (가)와 (나)를 <보기>와 같이 요약할 때, ⓐ와 ⓑ에 들어갈 단어를 각각 (가)와 (나)에서 찾아 쓰시오. [3.2점]
<보기> 두 글은 언어의 미세한 차이가 세계를 인식하는 태도와 감정을 바꾼다는 점을 보여준다. (가)는 ( ⓐ )와/과 정서를 구분하는 언어의 힘을, (나)는 ( ⓑ )을/를 해방으로 바꾸는 언어의 전환을 통해 말의 선택이 곧 사유의 방식임을 드러낸다.

(2) <보기>를 활용하여 ㉠과 ㉡에 대한 설명을 한 문장으로 쓰시오. [4.2점]
<보기> '격 조사'는 체언이나 체언 구실을 하는 말 뒤에 붙어 앞말이 다른 말에 대하여 갖는 일정한 자격을 나타내는 조사이고, '보조사'는 체언, 부사, 활용 어미 따위에 붙어서 어떤 특별한 의미를 더해 주는 조사이다.

(3) ㉢에 공통적으로 들어갈 말을 (나)에 있는 표현을 활용하여 쓰시오. [4.1점]

정답 · 채점 기준 (대학 공개)

(1) ⓐ 사실, ⓑ 강요 — 각 1.6점('강압'도 정답으로 인정)

(2) "㉠은 격조사를 사용하였고, ㉡은 보조사를 사용하여 특별한 의미를 더한다." 이런 의미의 문장이면 정답이며, 완성도에 따라 감점하거나 부분 점수를 줄 수 있습니다.

(3) '건성으로 해야 돼.'를 정확히 쓰면 정답

SN 해설

(1) <보기>에서 짝을 이루는 말을 먼저 찾습니다. ⓐ는 '정서'와, ⓑ는 '해방'과 대립합니다. (가)에서 '정서'와 맞서는 말은 ㉠ 문장의 "사실의 세계"입니다. (나)에서 '해방(감)'과 맞서는 말은 "강요가 아니라", "강압이 아니라 해방감"에 나옵니다. 빈칸 앞뒤에 있는 단어를 짝으로 놓고 반대말을 찾으면 됩니다.

(2) ㉠ "꽃이"의 '이'는 주어 자격을 나타내는 주격 조사로, <보기>의 '격 조사'에 해당합니다. ㉡ "꽃은"의 '은'은 대조·강조 같은 의미를 더하는 보조사입니다. 지문은 이것을 '정서를 섞어 넣은 것'이라고 설명합니다. 그러니 답안에는 ① ㉠=격 조사 ② ㉡=보조사 ③ 보조사가 특별한 의미(정서)를 더한다는 세 요소가 한 문장 안에 모두 들어가야 합니다.

(3) 빈칸 뒤에 단서가 세 개 있습니다. "건성으로 해도 돼"가 아니었다는 말, "해야 돼."의 단호한 어감, 그리고 그 말이 성실함의 반대말인 '건성'을 지지했다는 말입니다. 이 셋을 합치면 '건성' + '해야 돼'이므로 "건성으로 해야 돼."가 답입니다.

감점 피하기

  • (1) ⓐ는 (가)에서, ⓑ는 (나)에서 찾아야 합니다. '해방'과 '강요' 사이에 등장하는 '건성'이나 '숨통'은 답이 아닙니다.
  • (2) "㉡은 정서를 나타낸다"만 쓰면 <보기>의 문법 용어(격 조사/보조사)를 활용하지 않은 답이 됩니다. 반드시 두 용어를 다 쓰세요.
  • (3) '해도 돼'로 쓰면 지문이 명시적으로 부정한 표현이므로 오답입니다.

(1) 첫째항 $a$, 공비 $r$ 로 두면 $a(1+r+r^2) = 26$, $\frac{a}{1-r} = 27$ 입니다(무한등비급수가 수렴하므로 $-1 \lt r \lt 1$). 두 식을 나누면 $(1+r+r^2)(1-r) = 1 - r^3 = \frac{26}{27}$ 이므로 $r^3 = \frac{1}{27}$, 즉 $r = \frac{1}{3}$ 입니다. 그러면 $a = 27 \cdot \frac{2}{3} = 18$ 이고 $$a_4 = 18 \cdot \left(\tfrac{1}{3}\right)^3 = \frac{2}{3}.$$ 핵심은 $(1+r+r^2)(1-r) = 1-r^3$ 이라는 곱셈 공식을 알아보는 것입니다. 이것을 보면 삼차방정식을 풀 필요가 없습니다.

(2) 급수가 수렴하면 그 일반항은 0으로 갑니다. $\sum a_n$ 이 수렴하므로 $a_n \to 0$, 세 번째 급수가 수렴하므로 $a_n + b_n - \frac{3n^2-n}{9n^2-3n-2} \to 0$ 입니다. 분수식은 최고차항 계수 비로 $\frac{3}{9} = \frac{1}{3}$ 에 수렴하므로 $$\lim_{n\to\infty} b_n = 0 + \frac{1}{3} - 0 = \frac{1}{3}.$$

(3) 주어진 극한을 두 부분으로 나눕니다.

① 앞부분: $a_n + b_n \to 0 + \frac{1}{3} = \frac{1}{3}$.

② 뒷부분: $c_n = \frac{3n^2-n}{9n^2-3n-2}$ 이라 두고, $a_k + b_k - \frac{1}{3} = (a_k + b_k - c_k) + (c_k - \frac{1}{3})$ 로 쪼갭니다. 앞 괄호의 합은 조건에서 28입니다. 뒤 괄호를 통분하면 $$c_n - \frac{1}{3} = \frac{3(3n^2-n) - (9n^2-3n-2)}{3(9n^2-3n-2)} = \frac{2}{3(3n-2)(3n+1)} = \frac{2}{9}\left(\frac{1}{3n-2} - \frac{1}{3n+1}\right).$$ 망원급수(앞뒤 항이 지워지는 급수)이므로 합은 $\frac{2}{9}\left(1 - \lim \frac{1}{3n+1}\right) = \frac{2}{9}$ 입니다.

③ 합치면 $\frac{1}{3} + 28 + \frac{2}{9} = 28 + \frac{5}{9} = 29 + A$ 이므로 $A = -\frac{4}{9}$ 입니다.

분모 $9n^2-3n-2$ 를 $(3n-2)(3n+1)$ 로 인수분해하는 것이 이 문항의 열쇠입니다. 분자 계산 결과가 상수 2로 정리되는 것을 보고 부분분수 분해를 떠올려야 합니다.

감점 피하기

  • 부분분수 계수 $\frac{1}{3}$ 과 앞의 $\frac{2}{3}$ 를 곱해 $\frac{2}{9}$ 로 만드는 과정에서 계수를 하나 빼먹는 실수가 많습니다.

2번수학 · 미분과 적분 — 원의 접선, 삼각함수의 극한, 정적분과 급수12점

$k$ 가 자연수일 때, 중심이 원점이고 반지름이 $1$ 인 원 위의 점 $\mathrm{P}_k(\cos\theta_k,\ \sin\theta_k)$ 에 대하여 다음 물음에 답하시오. [12점] (단, $\theta_k = \dfrac{k\pi}{2n}$, $1 \le k \le n-1$ 이고, $n$ 은 $2$ 이상의 자연수)

(1) 점 $\mathrm{P}_k$ 에서의 접선과 $x$ 축 및 $y$ 축으로 둘러싸인 부분의 넓이를 $A_k$ 라 할 때, $A_k = \dfrac{1}{\sin\alpha_k}$ 를 만족한다. 이때, $\dfrac{\alpha_k}{\theta_k}$ 의 값을 구하시오. [3.3점]

(2) 점 $\mathrm{P}_k$ 를 지나는 접선의 기울기가 $m_k$ 일 때, 이 접선과 $x$ 축이 만나는 점을 $\mathrm{Q}_k$ 라 하고, 점 $\mathrm{P}_k$ 를 지나고 기울기가 $-\dfrac{1}{m_k}$ 인 직선과 $x$ 축이 만나는 점을 $\mathrm{R}_k$ 라 하자. 삼각형 $\mathrm{P}_k\mathrm{Q}_k\mathrm{R}_k$ 의 넓이를 $\dfrac{1}{2}f(\theta_k)$ 라 할 때, $\displaystyle\lim_{x\to 0}\frac{f(x)}{x}$ 의 값을 구하시오. [3.3점]

(3) 문제 (1)에서 구한 $A_k$ 에 대하여 $S_n = \displaystyle\sum_{k=1}^{n-1}\frac{1}{A_k}$ 일 때, $\displaystyle\lim_{n\to\infty}\frac{S_n}{n}$ 의 값을 구하시오. [5.4점]

정답 · 채점 기준 (대학 공개)

정답: (1) $2$ (2) $1$ (3) $\frac{2}{\pi}$

채점: 하위 문항별로 정답을 정확히 기입하면 만점(3.3점 / 3.3점 / 5.4점).

SN 해설

(1) $0 \lt \theta_k \lt \frac{\pi}{2}$ 이므로 $\mathrm{P}_k$ 는 제1사분면 위의 점입니다. 원의 접선은 반지름에 수직이므로 접선의 방정식은 $x\cos\theta_k + y\sin\theta_k = 1$ 입니다(음함수 미분 $y' = -\frac{x}{y}$ 로 구해도 같은 식). 절편은 $x$ 절편 $\frac{1}{\cos\theta_k}$, $y$ 절편 $\frac{1}{\sin\theta_k}$ 이므로 $$A_k = \frac{1}{2}\cdot\frac{1}{\cos\theta_k}\cdot\frac{1}{\sin\theta_k} = \frac{1}{2\sin\theta_k\cos\theta_k} = \frac{1}{\sin 2\theta_k}.$$ 따라서 $\alpha_k = 2\theta_k = \frac{k\pi}{n}$ 이고 $\frac{\alpha_k}{\theta_k} = 2$ 입니다. 배각 공식 $2\sin\theta\cos\theta = \sin 2\theta$ 를 바로 떠올리는 것이 포인트입니다.

(2) $\mathrm{Q}_k$ 는 접선의 $x$ 절편이므로 $\left(\frac{1}{\cos\theta_k}, 0\right)$. 기울기가 $-\frac{1}{m_k}$ 인 직선은 접선에 수직인 직선, 즉 $\mathrm{P}_k$ 에서의 법선이고, 원의 법선은 중심을 지나므로 $\mathrm{R}_k = (0,0)$ 입니다. 삼각형의 밑변은 $\overline{\mathrm{R}_k\mathrm{Q}_k} = \frac{1}{\cos\theta_k}$, 높이는 $\mathrm{P}_k$ 의 $y$ 좌표 $\sin\theta_k$ 이므로 넓이는 $\frac{1}{2}\tan\theta_k$ 입니다. 이것이 $\frac{1}{2}f(\theta_k)$ 이므로 $f(x) = \tan x$ 이고 $$\lim_{x\to 0}\frac{\tan x}{x} = \lim_{x\to 0}\frac{\sin x}{x}\cdot\frac{1}{\cos x} = 1.$$

(3) $\frac{1}{A_k} = \sin\frac{k\pi}{n}$ 이고, $k = n$ 일 때 $\sin\pi = 0$ 이므로 합의 범위를 $k = n$ 까지 늘려도 값이 같습니다. 그러면 $$\frac{S_n}{n} = \frac{1}{n}\sum_{k=1}^{n}\sin\frac{k\pi}{n} = \frac{1}{\pi}\sum_{k=1}^{n}\sin\left(\frac{k\pi}{n}\right)\cdot\frac{\pi}{n} \to \frac{1}{\pi}\int_0^{\pi}\sin x\,dx = \frac{1}{\pi}\cdot 2 = \frac{2}{\pi}.$$ 구분구적법에서는 $\Delta x = \frac{\pi}{n}$ 을 만들기 위해 $\frac{1}{n} = \frac{1}{\pi}\cdot\frac{\pi}{n}$ 으로 바꿔 쓰는 단계가 핵심입니다.

감점 피하기

  • (2)에서 $f(x)$ 를 넓이 자체($\frac{1}{2}\tan x$)로 착각하면 답이 $\frac{1}{2}$ 이 됩니다. 넓이가 $\frac{1}{2}f$ 라고 주어졌다는 점을 확인하세요.
  • (3)에서 $\frac{\pi}{n}$ 을 만들 때 생기는 $\frac{1}{\pi}$ 를 빠뜨리면 답이 $2$ 가 됩니다.
3번수학 · 정적분의 활용 — 넓이 함수와 급수의 합10점

정답 · 채점 기준 (대학 공개)

(2) $k \to \infty$ 이면 $\frac{1}{k^3}\left(\frac{1}{k} - \frac{4}{3}\right) \to 0$ 이므로 $\lim A(k) = \frac{1}{3}$ 입니다. 넓이로 보면 $\int_1^{\infty}\frac{1}{x^4}dx$ 에 해당하는 값입니다.

(3) $f_k = f\left(1 + \frac{k}{n}\right)$ 로 줄여 쓰면, 주어진 합은 $\frac{1}{n}\sum_{k=1}^{n} k(f_k - f_{k+1})$ 입니다. 펼쳐서 같은 $f_k$ 끼리 모으면 $$\sum_{k=1}^{n} k(f_k - f_{k+1}) = (f_1 + f_2 + \cdots + f_n) - n f_{n+1}$$ 이 됩니다(예: $f_2$ 는 $+2f_2$ 와 $-1\cdot f_2$ 에서 계수 1이 남습니다). 따라서 $$\text{(합)} = \sum_{k=1}^{n} f\left(1 + \frac{k}{n}\right)\frac{1}{n} - f\left(2 + \frac{1}{n}\right) \to \int_1^2 \frac{1}{x^4}dx - f(2) = \frac{7}{24} - \frac{1}{16} = \frac{11}{48}.$$ 이 값은 $\int_1^2 \left(f(x) - f(2)\right)dx = A(2)$ 이므로, (1)의 식에 $k = 2$ 를 넣어 $\frac{1}{3} + \frac{1}{8}\left(\frac{1}{2} - \frac{4}{3}\right) = \frac{11}{48}$ 로 검산할 수 있습니다.

5번수학 · 수열 — 등차수열과 절댓값의 합10점

공차가 $2$ 인 등차수열 $\{a_n\}$ 이 아래 조건을 만족한다. 다음 물음에 답하시오. (단, $k \ge 2$ 인 자연수) [10점]

가) $a_k = 0$
나) $a_1 + a_2 + a_3 + \cdots + a_m = 120$
다) $|a_1| + |a_2| + |a_3| + \cdots + |a_m| = 144$

(1) $a_1 + a_2 + \cdots + a_{k-1}$ 의 값을 구하시오. [4.3점]

(2) $a_1 = Ak + 2$ 일 때, 상수 $A$ 의 값을 구하시오. [3.2점]

(3) $m$ 의 값을 구하시오. [2.5점]

정답 · 채점 기준 (대학 공개)

정답: (1) $-12$ (2) $-2$ (3) $15$

SN 해설

(1) 공차가 양수이므로 $a_k = 0$ 앞의 항 $a_1, \ldots, a_{k-1}$ 은 모두 음수이고, 뒤의 항은 양수입니다. 두 합의 차이는 음수 항에서만 생깁니다. 음수 항의 합을 $N$ 이라 하면 조건 나)는 $N + P = 120$, 조건 다)는 $-N + P = 144$ ($P$ 는 나머지 항의 합). 빼면 $2N = -24$, 즉 $$a_1 + a_2 + \cdots + a_{k-1} = -12.$$ (만약 $m \lt k$ 이거나 모든 항이 같은 부호라면 두 합의 절댓값이 같아야 하는데 $120 \ne 144$ 이므로 불가능합니다. 따라서 $1 \lt k \lt m$ 입니다.)

(1) 빈칸 앞 문맥을 순서대로 정리합니다. 성능 향상 방법 = 비트 크기 줄이기 → 극한은 원자 하나 → 원자 크기에 가까워지면 합선 문제. 따라서 '이것'(합선 문제)은 고전 컴퓨터 방식으로는 더 이상 성능, 즉 첫 문장에 나온 '연산 처리 능력'을 높일 수 없다는 한계를 뜻합니다. 빈칸 뒤 '을/를 나타낸다'와 이어지도록 "연산 처리 능력을 향상시키기 어렵다는 것"처럼 명사형으로 끝맺습니다. 다음 문장의 "이러한 한계"가 정답 방향을 확인해 줍니다.

(2) <보기>의 "자릿수가 클수록 … 빠른 속도"는 마지막 단락의 "처리할 이진수의 자릿수가 클수록 양자 병렬성에 힘입어 연산 속도에서 압도적인 위력"을 바꿔 쓴 것입니다. 본문 용어 그대로 '양자 병렬성'을 씁니다.

(3) 규칙은 하나입니다. 제어 비트가 0이면 표적 비트 그대로, 1이면 뒤집기(NOT).

(0, 0) → 표적 0 그대로: ⓐ = 0 / (0, 1) → 표적 1 그대로: ⓑ = 1 / (1, 0) → 0을 뒤집어: ⓒ = 1 / (1, 1) → 1을 뒤집어: ⓓ = 0
