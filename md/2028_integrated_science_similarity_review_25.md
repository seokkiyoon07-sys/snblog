# 2028 통합과학 예시문항 25제 — 유사 기출 검토표

## 검토 기준

- **높음 · 직접 유사**: 예시문항의 핵심 판단 과정이 기출의 실제 선지에 직접 대응한다. 문항 전체가 동일하다는 뜻은 아니며 대응 범위를 함께 표시한다.
- **보통 · 부분 직접 연결**: 일부 선지·개념은 직접 대응하지만 예시문항의 중심 추론 전체를 연습하기는 어렵다.
- **낮음 · 보충 학습**: 배경 개념이나 자료 해석 방법을 공유하지만 중심 과제는 다르다.
- **낮음 · 심화 학습**: 관련 소재에 더해 예시문항 밖의 추가 지식·추론이 필요하다. 심화는 난도·학습 범위 표시이며 유사도가 높다는 뜻이 아니다.
- **미등록**: 현재 연결된 기출이 없다. 유사 기출 자체가 없다는 뜻은 아니다.
- **검토 대기**: 자료 등록 또는 원문·선지 대조가 필요하다.

소재나 그래프 모양의 유사성과 실제 풀이의 유사성을 구분한다. 유사도와 별도로 원본의 보기·선택지 오류 및 출처 확인 여부를 기록한다.

## 8번 — 기존 확인 사항

25문항의 현재 등록 자료에 대한 유사도 검토를 정리했다. 이는 모든 출처의 학년도·학년·과목을 외부 원본으로 검증했다는 뜻은 아니다. 3번은 미등록이며 8번 선택지 오류와 각 행의 출처 확인 사항은 미해결로 유지한다.

- `175062-1.png`: 같은 종의 얼룩말 줄무늬 차이를 다른 다양성 범주로 분류하는 선지는 원문 ㄱ과 직접 연결된다. 다만 제공 이미지의 보기대로라면 ㄷ만 옳은데 해당 선택지가 없어 **정답 번호 보류·원본 확인 필요** 상태다.
- `163382-1.png`: 유전적 변이와 자연 선택에 따른 집단의 변화가 원문 ㄷ과 연결된다. 획득 형질 유전은 추가 개념 점검이며, 원문의 빈도 그래프와 같은 유형의 자료 해석 문제는 아니다.
